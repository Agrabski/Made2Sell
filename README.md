# Made2Sell

Landing page for recruiting alpha testers for Made2Sell — inventory tracking for craft fair sellers.

## Features

- English and Polish language toggle
- Responsive mobile design
- Email signup form
- Simple, clean design

## Hosting

This site is hosted on GitHub Pages at `https://agrabski.github.io/made2sell`

## Local Development

Open `index.html` in a browser to preview locally.

To update, edit `index.html` and push to the `main` branch.
